## Допущения оценки

Минуты на проверку (константы `MINUTES` в `portions.py`; мои допущения, не замеры): scalar 2, formula 5, t54row 3, t54notes 6, t55row 0.8, bound 2, edition 3, control-point 3, control-point-empty 4; расхождение или запись одной стороны +3. Верификатор открывает PDF на нужной странице и сверяет значение с A и B. Не включены: чтение инструкции, перерывы, ответ на вопрос об Изм. № 5, назначение допуска ex1. Порция ограничена 60 мин; запись из нескольких строк (таблица 5.5) не делится.

Разбиение на P1–P3 следует `interim-normatives-source`, задачи 7.3a–7.3c; порядок внутри группы: расхождения и ambiguous первыми. Так порции P1 с формулой (5.7) идут первыми.
