[Отчёт сравнения на русском](../../akim/digitization/phase1b-2026-11-03/comparison/report-rus.md).
Все вердикты, corrected/by/at/comment и подпись оставлены пустыми.
Поля заполняются только по решению верификатора Akim.
Этот лист не подтверждает выбор методики по вопросам 10-13.
Исходные A/B и подписанные листы пилота не изменены.
Перенос статусов потребует будущий YAML типа и проверенную карту record_digest/items;
сейчас эти листы ещё не привязаны к рабочим записям будущего типа.

Это девять незаполненных контрольных точек: по две на каждую формулу и три
случая порога. Численные входы, ожидаемые результаты и допуски не назначались.
При их задании нужно обновить локальный манифест показанного содержимого,
Markdown и shown_digest перед записью окончательного вердикта и подписью.
Эти контрольные точки являются отдельной приёмкой: их нельзя использовать
вместо проверки исходной нормативной записи или связывать одной картой
переноса с записью из другой порции.
