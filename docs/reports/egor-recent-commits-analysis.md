## 1. Важное для работы Акима

### 1.1 Нет манифеста зависимостей

- В `pyproject.toml` нет `[project]` и `dependencies`. Нет `requirements*.txt` и нет lock-файла. Есть только `.python-version` (3.12.3).
- Код и ноутбук Егора используют: `psycopg2`, `pymorphy3`, `pdfplumber`, `sympy`, `pix2text`, `onnxruntime`, `doclayout_yolo`, `torch`, `transformers`, `cv2` (OpenCV), `sklearn`, `pymupdf` (`fitz`), `huggingface_hub`. Журнал описывает ещё `latex2sympy2`, но в закоммиченном коде и ноутбуке его нет (см. 1.3).
- Версии закреплены только в тексте журнала исследований: `antlr4==4.7.2` (запись 9), `transformers 4.57.6` (запись 3).
- Окружение сейчас не воспроизводится ни у тебя, ни в будущем CI.

Для WP6 (`bootstrap-dev-environment`) это первое решение:
- манифест и lock-файл;
- тяжёлые ML-зависимости (`torch`, `transformers`, `doclayout_yolo`, `pix2text`) — отдельной группой или extras, чтобы backend их не тянул.

### 1.2 Раскладка тестов уже задана Егором

- `pyproject.toml`: `testpaths = ["tests"]`, покрытие с ветвями только по `normatives_pipeline`.
- `pytest` из корня запускает тесты Егора. Тесты, которым нужна база (`test_db_payload`, `test_ingest`) или PDF в `norm-docs/` (`test_extractors_corpus`), пропускаются, если их нет.
- `tests/conftest.py` задаёт `DEC_DATABASE_URL` по умолчанию `postgresql://dec:dec@localhost:5433/dec`. В самом пайплайне отсутствие переменной — ошибка, а в тестах — тихий переход на localhost.

Для WP6: у backend должны быть свой путь тестов и своё покрытие. Иначе общий гейт ≥ 95% по ветвям смешает две зоны.

### 1.3 Сверка формул через `latex2sympy2`

Запись 8 журнала исследований. `sympy.parse_latex` ломает русскую нотацию: `\mathrm{tg}` → `g*t`, `\gamma_{II}` → `gamma_{I*I}`. Егор перешёл на `latex2sympy2` и сравнивает формулы по семантическому равенству SymPy-выражений.

**Оговорка.** `latex2sympy2` нет ни в закоммиченном коде (`normatives_pipeline/`, `tests/`), ни в `research.ipynb`: в сохранённых выводах ноутбука только строковая близость (`best_sim` 0.682 / 0.939 для 5.1 / 5.5). Поэтому результат записи 8 («5.5 и 5.7 совпадают семантически») и опирающийся на него вывод записи 10 («на пилотах косяков не было») по репозиторию воспроизвести нельзя. Это стоит попросить у Егора вместе с манифестом зависимостей.

Где это пригодится Акиму, когда код появится в репозитории:
- автоматическая сверка LaTeX ↔ `expression` при проверке формулы (показывать инженеру расхождения);
- кандидат для безопасного разбора выражений (риск в `design.md` WP2). Безопасность нужно проверить отдельно: разбор идёт через ANTLR, но внутреннее устройство я не смотрел.

### 1.4 Таблицы коэффициентов сохраняются

В `db.py` есть таблица `coefficient` (`table_number`, `page`, `row_index`, `col_index`, `value`). Номер таблицы определяется по подписи. Это нужно для R: коэффициенты `M_γ`, `M_q`, `M_c` берутся из таблицы 5.5 СП 22.13330.2016, `unverified`.

Но у значений нет `NormRef` и нет статуса проверки — это вопросы 11–12 к Егору.

### 1.5 Поиск

- Поиск работает через `pg_trgm similarity`. Порог задаётся в `parser.toml`, `[search] similarity_threshold`.
- Для frontend-поиска по нормам это готовое поведение. Вместе с нормализацией из ML-журнала (записи 16–17: нижний регистр, ё→е, лемматизация) его стоит записать требованием в спеке каталога.

## 2. Риски: сказать Егору и PM

### 2.1 Лицензии компонентов не проверены

В конвейер вошли:
- DocLayout-YOLO (на базе YOLOv10) — детекция формул;
- PyMuPDF (`fitz`) — рендер страниц;
- pix2text (`LatexOCR`, `mfr-1.5`) — распознавание;
- датасет im2latex-230k — задел под свою модель.

Насколько мне известно, PyMuPDF и семейство YOLO от ultralytics распространяются под AGPL-3.0. Это **не сверено** с их текущими лицензиями. Если так, использование в коммерческом облачном сервисе (B2B/B2C) требует решения PM: юридического или замены компонента. Лицензию датасета нужно проверить до того, как дообучать на нём модель.

### 2.2 Изображение страницы СП в закоммиченном ноутбуке

`normatives_pipeline/research/research.ipynb`: в выводе ячейки 3 лежит `image/png` — результат детекции на стр. 38 СП 22.13330.2016. Страницы и вырезки при этом исключены в `.gitignore` (`research/pages/`, `research/crops/`). Правовой статус текстов норм (C5) не решён, а в `.gitignore` для `norm-docs/` прямо сказано «full texts are not redistributed».

Предложение Егору: очищать выводы ноутбука перед коммитом (например, `nbstripout`) и убрать изображение из истории, если PM сочтёт это нужным.

### 2.3 `CREATE EXTENSION pg_trgm` в `init_schema`

Это требует прав суперпользователя. Когда появятся роли по зонам и роль только для чтения (вопрос 8 к Егору), расширение нужно ставить при развёртывании базы, а не при загрузке. Это затрагивает compose (Егор) и WP5 (задачи 9.1–9.2).

### 2.4 Процесс: код влит до GO

Код `normatives-formula-contract` влит в `develop` при 0/20 задач: не отмечены ни DOR, ни `openspec validate`, ни `spec-reviewer`, ни вердикт `tester`. По `AGENTS.md` (жизненный цикл, шаг 7) код вливается после GO; ранее вливаться могут только документы без кода. Зона Егора, но это отступление от общего процесса, закреплённого в WP7.
