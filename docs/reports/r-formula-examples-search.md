# Отчёт: поиск примеров расчёта R в методичках `docs/NTD/methodical_guides`

Дата: 2026-09-27. Для Акима. Подготовлено с помощью Claude Code.

Задача: проверить, есть ли в методичках не меньше трёх разобранных примеров расчёта R (расчётное сопротивление грунта основания, формула 5.7, п. 5.6.7 СП 22.13330.2016) — предварительного кандидата в первый тип расчёта `foundations-shallow` (`docs/decisions/first-calculation-type-egor-pm-rus.md`, вопрос 2).

## Метод

В `docs/NTD/methodical_guides/` лежат три PDF. Текст извлечён через `pdftotext -layout`, дальше — построчный поиск по «расчётное сопротивление», «R =», номерам формулы и характерным коэффициентам (γc1, γc2, Mγ, Mq, Mc). Для каждого найденного применения формулы проверено: (а) есть ли полная числовая подстановка всех величин, (б) на какой документ и редакцию ссылается пособие — по его собственному списку литературы.

## Результат

**Условие выполнено с большим запасом, независимо в двух пособиях из трёх.**

### 1. `Calc_OiF_Linkovskiy.pdf` — источник СП 22.13330.2016, взят как основной

Несмотря на имя файла («Linkovskiy»), автор в тексте — **С. В. Линовский** (без «к» после «Лин»), в соавторстве с Т. А. Якушкиной. Полное название: «Проектирование и расчёт фундаментов мелкого заложения на естественном основании (примеры расчёта)», методические указания, НГАСУ (Сибстрин), 2023, утверждены 2023-06-13.

Формула прямо цитируется как «[2, формула (5.7)]», пункт 2 списка литературы — «СП 22.13330.2016. Основания зданий и сооружений: актуализированная ред. СНиП 2.02.01-83*, изм. 1–4, введ. 2017-07-01». Это та же редакция, на которую опирается пайплайн Егора.

Найдено 5 независимых числовых применений формулы:

| Стр. | Задача | R / Rz |
|---|---|---|
| 7 | Пример 1, фундамент мелкого заложения, пробная ширина b=1,5 м | R=200,34 кПа |
| 8 | Пример 1, та же задача, уточнённая ширина b=2,1 м | R=206,16 кПа |
| 16 | Пример 1, проверка слабого подстилающего слоя (условный фундамент) | Rz=855,9 кПа |
| 21 | Пример 2, ленточный фундамент, пробная ширина b=0,6 м | R=254,57 кПа |
| 23 | Пример 2, та же задача, уточнённая ширина b=1,8 м | R=273,71 кПа |

### 2. `Metodrekomendacii_po_RGR_Osnovaniya_i_fundamenty.pdf` — тоже СП 22.13330.2016

Список литературы: пункт 2 — «СП 22.13330.2016 Основания зданий и сооружений: актуализированная редакция СНиП 2.02.01-83*». В тексте формула названа своей внутренней нумерацией «(7)» (пособие нумерует формулы последовательно по документу), но структура и коэффициенты те же.

Найдено ещё 5 применений (стр. 11–12, 14, 19, 21), результаты R от 354 до 1874,7 кПа — разные грунты и схемы (фундамент мелкого заложения, лента, свайный).

### 3. `OiF.pdf` — не использован для этого типа

Формула цитируется как «формула (7) СНиП 2.02.01-83*» — это **предыдущая редакция**, не СП 22.13330.2016 напрямую (список литературы, пункт 6: «СНиП 2.02.01-83*. Основания зданий и сооружений. М., Госстрой России, 1995»). Структура формулы та же, но `source_norm_edition` для этих примеров был бы другим. Для эталонов не брался, чтобы не смешивать редакции в одной пилотной пробе.
