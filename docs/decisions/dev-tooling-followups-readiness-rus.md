   коммит которого везёт обновление только номеров строк, теряло бы путь GO без кода).
   Решено расширением определения «no code»: изменённое требование «Go/No-Go verdict and
   archive» и `AGENTS.md`, раздел 4, говорят, что такое обновление не делает изменение
   изменением с кодом. Ответ Егора от 2026-10-04 покрывает только предложение в разделе
   2, поэтому задача 5.1 просит его подтвердить предложение в разделе 4.

   разошёлся бы с базовой спецификацией. Решено порядком: правка (задача 5.2) — после GO
   и ревью (6.2), в одной сессии с архивом (6.3).
