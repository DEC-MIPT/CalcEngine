## Что изменилось

Листы проверки временных нормативных данных и файл проверенных данных содержат хеши SHA-256
в шестнадцатеричном виде. `detect-secrets` помечает каждый как строку с высокой энтропией, а
шагу переноса нужны листы в git. Поэтому Аким изменил два общих файла:

| # | Файл | Изменение | Где | Коммит |
|---|---|---|---|---|
| 1 | `.gitignore` | `!docs/verification/` и `!docs/verification/**`: git отслеживает папку листов проверки, как и `docs/decisions/` | `develop` | `b30ed49` |
| 2 | `.pre-commit-config.yaml` | `detect-secrets` пропускает `docs/verification/**.yaml` (листы с `shown_digest` и хешем подписи); Markdown-версии по-прежнему проверяются | `develop` | `b30ed49` |
| 3 | `.pre-commit-config.yaml` | `detect-secrets` также пропускает `backend/interim_normatives/**.yaml` (записи с `value_digest`); схема этих файлов запрещает неизвестные поля | `feature/interim-normatives/backend`, вливается вместе с фичей | `f33df61` |

Изменения 1 и 2 сделаны прямо в `develop`. `AGENTS.md`, раздел 2, относит оба файла к коду,
который идёт через feature-ветку; Аким выбрал `develop`, чтобы папка сразу отслеживалась у
всех (2026-10-27). `.secrets.baseline` не изменился, `pre-commit run --all-files` проходит.
