## 1. Первый тип расчёта

В методичке должно быть не меньше 3 разобранных примеров типа (решение 1 WP4: N = 3;
меньше — набор недействителен). Предлагать тип (типы) по тому, что методичка
действительно охватывает; решение попадает в «In-scope calculation types»
`foundations-shallow` через Егора и PM.

Предварительный кандидат: расчётное сопротивление грунта основания R, формула 5.7, пункт
5.6.7 СП 22.13330.2016 (номера из `formulas.toml` Егора, `unverified`). Формула есть в
реестре Егора, и СП загружен; сначала проверить, что в методичке не меньше 3 разобранных
примеров R.

Тест Егора `tests/test_formula_code.py` вычисляет R = 143.75 кПа из произвольных
входных значений. Он проверяет только связь формулы с кодом; ссылки на источник у него
нет, поэтому это не эталонный пример, и в набор его допускать нельзя.

- Предлагаемый тип (типы): расчётное сопротивление грунта основания, R (формула 5.7,
  пункт 5.6.7, СП 22.13330.2016), формулировка методички «расчётное сопротивление грунта
  основания».
- Разобранные примеры в методичке: проверены две из трёх PDF в
  `docs/NTD/methodical_guides/` (обе ссылаются прямо на СП 22.13330.2016; третья,
  `OiF.pdf`, ссылается на более старый СНиП 2.02.01-83* и для этого типа не используется).
  В `Calc_OiF_Linkovskiy.pdf` (выбрана источником, раздел 2): 5 различных численных
  применений формулы 5.7 — стр. 7-8 (Пример 1, пробная и уточнённая ширина), стр. 16
  (Пример 1, проверка `Rz` более слабого подстилающего слоя), стр. 21-23 (Пример 2,
  пробная и уточнённая ширина). В `Metodrekomendacii_po_RGR_Osnovaniya_i_fundamenty.pdf`
  ещё 5 (стр. 11-12, 14, 19, 21), она может позже служить вторым источником, если
  понадобится больше 3 примеров. Это заметно больше требуемых 3.
- Согласовано Егором и PM: 2026-09-27. Егор подтвердил кандидата в
  `first-calculation-type-egor-pm.md`, вопрос 2, до того как был проверен этот подсчёт;
  PM устно одобрила Акиму в тот же день (доступа к репозиторию у неё пока нет, ответ
  записан от её имени; тот же файл, вопрос 2, «Answer (PM)»). На вопросы 1 и 2 теперь
  ответили оба.

## 3. Примеры

Ниже заполнены три примера, все из источника раздела 2 (Линовский/Якушкина, 2023).
Id символов совпадают с записью формулы 5.7 в реестре Егора
(`normatives_pipeline/formulas.toml`, `unverified`). `tolerance`, `tolerance_kind` и
`tolerance_source` оставлены для заполнения инженером (Акимом); больше ничего здесь не
фиксирует значений нормы сверх того, что уже указано в методичке и реестре.

**Соответствие пилоту (2026-10-05).** Пилот `foundations_shallow_r` принимает `φII` как
вход и выбирает по нему `Mγ`, `Mq`, `Mc` из таблицы 5.5, по точному совпадению с целым
градусом (правила интерполяции у таблицы нет, страницу 38 проверил Аким). `γc1`, `γc2` и
`k` он берёт из каталога, где по одной строке: `γc1 = 1.1`, `γc2 = 1.0`, `k = 1.0`
(`normative-catalog-pilot-coefficients-egor.md`). Поэтому:

- в каждую карточку нужен `φII`, который использовала методичка, со страницы примера, и
  проверка, что это целый градус, строка которого в таблице 5.5 даёт `Mγ`, `Mq`, `Mc`
  карточки;
- `ex1` (`γc1` = 1.1) подходит; `ex1-rz` (1.4) и `ex2` (1.25) не подходят, пока у пилота
  нет входа, выбирающего строку грунта в таблице 5.4, или `γc1` не принимается как вход
  (Аким и PM, вместе с вопросом слоистого основания);
- `d_1` в `ex2` (0.53 м) — приведённая глубина по формуле (5.8), посчитанная методичкой;
  пилот принимает `d_1` как вход, так что карточка остаётся корректной.

### Инварианты `foundations_shallow_r`, подтверждены 2026-10-06 (задача 2.11)

Подтверждены инженером (Аким) 2026-10-06. Формула — (5.7) СП 22.13330.2016 в том виде, в
каком её даёт реестр Егора (`formulas.toml`, `unverified`):
`R = (γc1·γc2/k)·[Mγ·kz·b·γII + Mq·d1·γ'II + (Mq − 1)·db·γ'II + Mc·cII]`, проверка `p ≤ R`.
Условия, которые инженер проверил по таблице 5.5 (стр. 38): все коэффициенты
неотрицательны, и `Mq ≥ 1` во всех строках.

|---|---|---|---|---|
